claude-jobs 隱私權政策

最後更新：2026-11-26

  • 使用者：本工具只供擁有者本人使用，只會存取擁有者自己的 Google 帳號。
  • 存取的資料：透過 Gmail API 的唯讀權限（gmail.readonly），只讀取特定寄件者寄來的每日報告信。不會傳送、刪除或修改任何信件。
  • 資料用途：信件內容會送到 Anthropic 的 Claude API 產生摘要，摘要存進擁有者自己的私人 GitHub repository。資料不用於其他用途。
  • 分享：除了上述處理所必需的服務供應商（Google、Anthropic、GitHub），不會把資料提供、出售或揭露給任何第三方。
  • 保存與刪除：摘要保存在擁有者的私人 repository，由擁有者自行管理。擁有者可隨時到 Google 帳戶的「第三方存取權」撤銷授權。
  • Google API 資料使用：本工具使用 Google API 取得的資料，遵守 Google API Services User Data Policy，包括 Limited Use 要求。

Privacy Policy (English)

  • Users: This tool is used only by its owner and accesses only the owner's own Google account.
  • Data accessed: Using the read-only Gmail scope (gmail.readonly), it reads daily report emails from a specific sender. It never sends, deletes, or modifies email.
  • Use: Email content is sent to Anthropic's Claude API to produce summaries, which are stored in the owner's private GitHub repository. Data is not used for any other purpose.
  • Sharing: Data is not sold, shared, or disclosed to third parties other than the service providers needed for the processing above (Google, Anthropic, GitHub).
  • Retention and deletion: Summaries stay in the owner's private repository under the owner's control. Access can be revoked at any time under "Third-party apps & services" in the Google Account.
  • Google API data: Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
