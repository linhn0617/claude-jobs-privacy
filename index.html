claude-jobs

claude-jobs 是個人使用的自動化工具，不對外提供服務。它以唯讀權限讀取擁有者本人 Gmail 信箱中特定寄件者的每日報告信，整理成摘要後存進擁有者自己的私人筆記庫。

隱私權政策

claude-jobs is a personal automation tool used only by its owner. It reads, with read-only access, a few daily report emails from one sender in the owner's own Gmail account and saves summaries to the owner's private notes repository. It is not offered to anyone else. See the privacy policy.
